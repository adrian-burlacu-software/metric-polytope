## Statements

- **unit-rectangle-class** (sufficient): If all weights are 1 and the equivalence on node pairs generated by 'opposite sides of a geodesic rectangle (a, a2, b, b2 with a2, b2 both between a and b and a, b both between a2 and b2)' puts all edges in one class, then the graph is a ray.
- **rectangle-propagation** (sufficient): If, after identifying opposite sides of every geodesic rectangle, the length of one class of node pairs determines all others by repeatedly applying geodesic triples d_ab = d_am + d_mb in which only one class is still undetermined, then the graph is a ray.
- **exchange-closure** (sufficient): If the geodesic exchange closure succeeds: merging classes of node pairs whenever an odd closed chain of geodesic exchanges (A + B = C + D from two geodesic triples sharing a class) forces equal length, and then propagating one class length through geodesic triples with a single undetermined class, determines every pair, then the graph is a ray.
- **unweighted-closure-necessary** (necessary): (Conjecture) If all weights are 1 and the graph is a ray, then the geodesic exchange closure succeeds: merging classes of node pairs whenever an odd closed chain of geodesic exchanges (A + B = C + D from two geodesic triples sharing a class) forces equal length, and then propagating one class length through geodesic triples with a single undetermined class, determines every pair.
- **split-prime** (necessary): A ray has no split {A, B} of its node set with positive isolation index: for every split there are a, a2 in A and b, b2 in B (repetitions allowed) with d_aa2 + d_bb2 >= max(d_ab + d_a2b2, d_ab2 + d_a2b).
- **geodesic-exchange-connected** (necessary): In a ray every edge lies in the symmetric difference of two geodesics joining the same pair of nodes, these symmetric differences connect all edges into one block, and the sum over node pairs of (number of geodesics - 1) is at least (number of edges - 1).
- **exchange-quotient-connected** (necessary): In a ray, after merging node pairs forced equal by odd closed chains of geodesic exchanges, every class occurs in a geodesic-triple relation, these relations connect all classes, and their number is at least the number of classes minus 1.
- **combined-necessary** (necessary): A ray on at least 3 nodes is 2-connected, has no split with positive isolation index, has its edges connected by geodesic exchanges with enough exchanges, and has a connected exchange quotient with at least (classes - 1) relations.
